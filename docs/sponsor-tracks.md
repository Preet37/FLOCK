# Sponsor Tracks and Submission Rules

Detailed requirements for the tracks in `FLOCK_CONTEXT.md` section 15 (fit and owners are listed there).
Source: team research from the Hacker Guide, Devpost and sponsor emails as of Oct 22. Check Hive and Devpost for changes.

## Submission (everyone)

- **Deadline: Sunday Oct 25, 9:00 AM local.** Include the repo, a project image and a working demo.
- Judging 10:30 AM–12:30 PM, full team at the table.
- Pitch: the Guide says 2 minutes; Devpost says 3 minutes + 2 minutes Q&A. Prepare a tight 2-minute core demo.
- All build work must start during the event.

## Tracks we're targeting

### Hyphenate: The Hyphenated Enterprise (main target)
Build an autonomous system for specific finance-team roles at an imagined company. Handle messy records, approvals, limited access and auditable decisions.
**Submit:** live demo; a video that **opens with the key catch/recovery**; the roles filled; and proof that separates real from simulated.
Prizes: $8,000 / $5,000 / $3,000; expedited interviews for every member of the top 5 teams.
See `docs/hyphenate-track.md`.

### SpacetimeDB: Best Use of Spacetime (Ira)
Spacetime must be the core real-time backend (shared state, instant sync, agent coordination, live dashboards) and play a meaningful role.
Prizes: $2,048 / $1,024 / $512. For us: findings, agent status and the audit log live in Spacetime; the dashboard updates live. `flock/store.py` has 6 methods to re-implement.

### Microsoft: Built for the Real World / Customer Impact Award
Production-minded AI agent. Judged on customer understanding, measurable usefulness, production path, responsible design and end-to-end functionality.
Prizes: 1st Surface laptops + tech talk + mentorship; 2nd tech talk + mentorship.

### Figma: Idea to Demo
Working demo, video ≤3 min, stage log (≤200 words per stage), Figma Slides with an embedded Make/prototype. Cover ideation, prototyping, handoff and code generation; for each tool, give time spent, a 1–5 effectiveness score and how it was used in the final project. Public Figma access required. **Log as you go.**
Prize details conflict (brief: $500 / $500 / $2,000 / $2,000; Devpost: five $1,000 cards). Confirm at the booth.

### Notability: Trust the Process
Document how the idea evolves in Notability, using handwriting, audio, diagrams, PDFs and Smart Notes, all tied to the actual build. Code `CALHACKS` gives a month of Pro. Prize: 1-year Pro + merch. (The pipeline sketch in `docs/pipeline-sketch.png` is the kind of thing to keep there.)

### Fetch.ai: Best Use of Fetch.ai (stretch, only if ahead)
Register on Agentverse, implement the Agent Chat Protocol, make the main workflow usable inside ASI:One, keep the repo public, and submit through both Devpost and the ASI:One submission agent. Wants a 3–5 min video and agent names/addresses in the README. Rubric: functionality 25%, Fetch use 20%, originality 20%, usefulness 20%, presentation 15%. Prize figures conflict ($1,500/$1,000/$500 vs $1,250/$750/$500 + two $250).

### Anthropic: Claude for Public Benefit (worth a look)
Use Claude to solve a real problem for a specific community. Show lived experience or user research, one usable workflow, and thoughtful use of Claude, including failure cases. Prize: $5,000 in Claude credits + 1 year of Claude Max 20x + Anthropic office hours. We already use Claude for the judges and dispute drafts, and the panel's "send to a human" path is a failure case we can show.

### CRS (skip)
Needs CRS credit/identity data at the center. Don't bend the idea to fit it.
